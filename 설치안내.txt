동요샘 노래상자 설치 안내 (한 시트 방식)
=========================================

선생님들은 아무것도 설치하지 않아요. 운영진이 서버 시트 하나만 만들면 됩니다.

[1] 운영진이 한 번만: 서버 만들기 (동요샘 전용 구글 계정으로)
  동요샘 전용 구글 계정으로 로그인한 상태에서 해요. 시트·드라이브 파일·알림 메일이 모두 이 계정에 모여요.
  1. 구글 시트를 새로 만들고 이름을 "동요샘 노래상자"로 정합니다.
  2. 확장 프로그램 > Apps Script 를 열고, 들어 있는 내용을 지운 뒤 Collector.gs 내용을 모두 붙여 넣고 저장합니다.
  3. 운영진 비밀번호 정하기: 코드 아래쪽 setOperatorPassword 안의 "새비밀번호"를 원하는 비밀번호로 바꾸고 저장한 뒤,
     위쪽 함수 목록에서 setOperatorPassword 를 골라 실행 버튼을 누릅니다. (처음 한 번 권한 허용 창이 뜹니다)
     실행한 뒤에는 코드 안의 비밀번호를 다시 "새비밀번호"로 돌려 두어도 괜찮아요. (암호로 바꿔 따로 저장돼 있어요)
  4. 함수 목록에서 allowMail, allowDrive 를 차례로 한 번씩 실행해 권한을 허용합니다. (알림 메일, 파일 올리기용)
  5. 배포 > 새 배포 > 유형: 웹 앱
     - 다음 사용자로 실행: 나
     - 액세스 권한이 있는 사용자: 모든 사용자
     배포 후 나오는 웹 앱 주소(…/exec)를 복사합니다.
  6. 그 주소를 저장소 national.json 의 collector 칸에 넣습니다. (주소를 보내 주시면 넣어 드려요)
     넣기 전까지 노래상자는 예시 기록으로 돌아가는 체험 모드예요.

[1-2] 회원방 대화방을 실시간으로: 파이어베이스 (한 번만)
  파이어베이스가 없어도 회원방은 모두 돌아가요. 대화방만 몇 초마다 새 말을 받아 오는 방식이 돼요.
  파이어베이스를 연결하면 말이 바로바로 오가고, 지금 들어와 있는 회원이 보여요.
  1. 동요샘 전용 구글 계정으로 파이어베이스 콘솔에서 프로젝트를 만듭니다.
  2. 빌드 > Realtime Database > 데이터베이스 만들기 (위치: 싱가포르 asia-southeast1, 잠금 모드)
     만든 뒤 '규칙' 탭에 파이어베이스_규칙.txt 의 내용을 붙여 넣고 [게시]
  3. 빌드 > Authentication > 시작하기 (따로 켤 로그인 방법은 없어요)
  4. 프로젝트 설정 > 일반 > 내 앱 > 웹 앱(</>) 추가 → 나오는 firebaseConfig 값을 national.json 의 firebase 칸에 넣습니다.
     (공개돼도 괜찮은 값이에요. 보내 주시면 넣어 드려요)
  5. 프로젝트 설정 > 서비스 계정 > [새 비공개 키 생성] → JSON 파일이 내려받아집니다. (이 파일은 비밀이에요. 아무에게도 보내지 마세요)
  6. Apps Script 편집기 왼쪽 톱니바퀴(프로젝트 설정) > 맨 아래 스크립트 속성 > 속성 추가
     - 속성: FIREBASE_SA
     - 값: 5번 JSON 파일을 메모장으로 열어 { 부터 } 까지 전체를 복사해 붙여 넣기
     저장한 뒤 함수 목록에서 checkFirebase 를 실행해 "키가 잘 들어갔어요"가 나오면 끝이에요.

[2] 운영진 메뉴 (노래상자 화면 맨 아래 '운영진')
  들어갈 때 운영진 이름과 운영진 비밀번호를 적어요. 비밀번호는 함께 쓰고, 이름은 '운영 기록'에 남아요.
  왼쪽(휴대폰은 위쪽) 메뉴에서 골라요. 마지막에 본 메뉴를 기억해요.
  - 한눈에 보기: 승인 기다리는 선생님, 확인할 가사, 공개 동의 확인할 곡, 이번 달 오늘의 동요를 한 번에 봐요.
  - 계정 승인: 가입 신청을 승인하거나 거절합니다. 비밀번호를 잊은 선생님께는 '임시 비밀번호'를 만들어 알려 드립니다.
  - 곡 관리: 새 곡 올리기, 고치기, 숨기기, 지우기. 작사·작곡 선생님께 공개 동의를 받았다는 칸에 표시해야 저장돼요.
             곡 종류는 '창작곡'과 '편곡' 중에서 골라요. 편곡이면 원곡 작사·작곡과 편곡한 선생님을 적어요.
             발표회 없이 개인이 만든 곡이면 '발표회 없이 개인이 만든 곡이에요'에 표시해요. (노래 찾기에서 '개인 창작곡'·'편곡한 노래'로 묶여요)
             계절은 여러 개 고를 수 있고, 네 계절 모두 어울리면 '사계절 모두'를 눌러요.
             '노래 파일 올리기'로 mp3를, '악보 올리기'로 PDF나 그림 악보를 바로 올려요. (한 파일 20MB까지,
             운영진 구글 드라이브의 '동요샘 노래상자 파일' 폴더에 저장되고 링크가 있는 사람만 볼 수 있게 공유돼요)
             영상 주소에 유튜브 주소를 넣으면 화면 안에서 바로 재생돼요.
             여러 곡을 한꺼번에 올릴 때는 '엑셀로 한꺼번에 올리기' → 양식 파일 받기 → 한 곡에 한 줄씩 적기
             → 표 전체를 복사해 붙여 넣기(또는 파일 고르기) → 미리보기 확인 → 'N곡 올리기'.
             양식을 구글 시트로 바꿔 공유하면 선생님들이 함께 적을 수 있어요. '공개 동의' 칸이 O인 곡만 올라가고,
             올라간 곡은 '공개 동의 받음'에 저절로 체크돼요. 같은 제목이 이미 있는 곡은 건너뛰어요.
             아래 플레이어 막대의 재생 버튼을 누르면 노래(없으면 영상)가 작은 창으로 재생되고, 다른 메뉴로 가도 계속 들려요.
             노래방 화면에서도 '노래 틀기'로 함께 틀 수 있어요.
  - 오늘의 동요 달력: 날마다 첫 화면에 나올 곡과 한마디를 한 달씩 미리 정해요.
             '빈 날 자동으로 채우기'로 계절 노래를 한 번에 넣고 하루씩 바꾼 뒤 '저장'을 누릅니다.
             정하지 않은 날은 계절 노래 가운데서 자동으로 골라요.
  - 가사 확인: 반에서 올린 바꾼 가사를 공개하거나 숨기기
  - 이어 부르기 릴레이: 릴레이 이름과 곡 정하기 (이름을 바꾸면 새 릴레이가 처음부터 시작)
  - 참여 반: 알맞지 않은 반을 전국 무대에서 숨기기
  - 기록 내려받기: 반별·곡별 기록을 엑셀에서 열리는 CSV 파일로 받아요.
  - 메일 설정: 비밀번호 문의 이메일(로그인 화면에 보임)과 알림 이메일(가입 신청·새 가사가 오면 메일, 화면에 안 보임)
  - 운영 기록: 어느 운영진이 언제 무엇을 했는지 보여요.
  - 계정 승인의 '회원방 신청': 동요샘 회원이라고 신청한 선생님을 '동요샘 회원 승인'으로 받아 줘요. 승인하면 회원방이 열려요.
    노래상자 가입 승인과 회원 승인은 따로예요. 회원이 아닌 전국 선생님도 노래상자는 그대로 쓸 수 있어요.

[2-2] 동요샘 회원방 (메뉴 맨 오른쪽 '회원방')
  - 자료방: 악보·반주(MR)·음원·가사·수업 자료·공연 자료를 올리고 받아요. 자료마다 '회원만'과 '누구나'를 골라요.
           '회원만' 자료는 회원이 아니면 목록·제목·파일 어느 것도 보이지 않고, 드라이브 파일도 비공개로 저장돼요.
           (앨범 가사·악보·음원은 꼭 '회원만'으로 올려 주세요)
           '누구나' 자료는 로그인하지 않은 사람도 목록을 보고 받을 수 있어요.
  - 일정: 모임·연습·발표회 일정을 보고 '참석 표시'를 해요.
  - 공지: 공지를 읽고 댓글을 달아요.
  - 곡집 원고: 곡마다 원고 PDF(A4 세로, 위 25mm·아래 20mm 여백, 쪽 번호 없이)를 내요.
  - 대화방: 회원끼리 이야기를 나눠요.
  - 화상 회의: 운영진이 걸어 둔 회의 주소(구글 미트 등)로 들어가요. 들어간 선생님 이름이 보여요.
  운영진 메뉴에 로그인한 기기로 회원방에 들어가면 회원 계정이 없어도 '운영진' 이름으로 들어오고, 운영진 일이 함께 보여요.
  - 일정 올리기·지우기, 공지 쓰기·고정·지우기, 다른 선생님 자료 고치기·지우기, 댓글 지우기
  - 곡집 제목 정하기, 원고 '검토 완료' 표시, 원고를 골라 '곡집 PDF 만들기' (표지·차례·쪽 번호가 붙은 한 권)
  - 화상 회의 주소 걸기

[3] 선생님이 쓰는 방법
  1. 노래상자 주소(https://dongyossam.github.io/)로 들어가 '우리 반' 메뉴에서 '처음이에요 · 가입 신청'
     아이디, 비밀번호, 이름, 학교, 지역을 적습니다.
  2. 운영진이 승인하면 로그인합니다.
  3. '반 만들기'로 우리 반을 만듭니다. 전담 선생님은 반을 여러 개 만들고 골라 가며 쓸 수 있어요.
     반 이름은 전국 무대에 보이니 지역 두 글자 + 학교 이름 + 반으로 적어 주세요. (예: 서울햇살초 5-1)
  4. 노래를 부른 뒤 스티커 붙이기, 이달의 노래 투표, 릴레이 이어받기, 바꾼 가사 올리기를 합니다.

[4] 서버 코드를 새로 바꿀 때 (주소는 그대로예요)
  1. Apps Script 편집기에서 내용을 모두 지우고 새 Collector.gs 를 붙여 넣고 저장합니다.
     (운영진 비밀번호는 이미 저장되어 있으니 setOperatorPassword 는 다시 실행하지 않아도 돼요)
  2. 새 권한이 필요한 판이면 allowMail, allowDrive 를 한 번씩 실행해 권한을 허용합니다.
  3. 배포 > 배포 관리 > 연필(수정) > 버전: 새 버전 > 배포

[참고]
  - 시트에는 계정·반·곡 목록·설정·바꾼 가사·릴레이 기록·오늘의 동요·운영 기록 탭이 자동으로 생겨요. 시트에서 직접 고쳐도 됩니다.
  - 회원방을 처음 쓰면 회원방 자료·일정·공지·댓글·대화·곡집 원고 탭이 생기고,
    드라이브의 '동요샘 노래상자 파일' 폴더 안에 '회원방 - 누구나 자료', '회원방 - 회원만 자료', '회원방 - 곡집 원고' 폴더가 생겨요.
    '회원만'과 '곡집 원고' 폴더는 공유하지 마세요.
  - 비밀번호는 암호처럼 바꿔서 저장되어 시트에서도 원래 비밀번호를 알 수 없어요.
  - 학생 이름 같은 개인정보는 저장하지 않아요.
  - 고친 내용은 2분 안에 화면에 반영됩니다. 바로 보고 싶으면 편집기에서 clearBoardCache 를 실행합니다.
  - 선생님이 로그인할 때 '30일 동안 로그인 유지'를 고르면 그 기기에서 30일 동안 다시 로그인하지 않아도 돼요.
  - 전국 무대와 많이 불린 순위는 '이번 달'(매달 1일 새로 시작)과 '올해'(3월 1일부터) 중에서 골라 볼 수 있어요.
