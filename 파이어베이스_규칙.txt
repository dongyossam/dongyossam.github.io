동요샘 회원방 - 파이어베이스 실시간 데이터베이스 규칙
=====================================================

넣는 곳: 파이어베이스 콘솔 > 빌드 > Realtime Database > 규칙 탭
아래 줄 사이의 내용만({ 부터 마지막 } 까지) 복사해, 원래 내용을 모두 지우고 붙여 넣은 뒤 [게시]를 누르세요.
설명 글까지 붙여 넣으면 'Parse error'가 나요.

- 노래상자 서버가 동요샘 회원으로 승인한 선생님의 구글 계정만 출입 명단(members)에 적어 두고,
  명단에 있는 사람만 대화를 읽고 쓸 수 있어요. 출입 명단은 서버만 고칠 수 있어요.
- 자기가 쓴 말만 지울 수 있어요. (운영진 메뉴에 로그인한 상태로 대화방에 들어온 회원은 다른 말도 지울 수 있어요)
- 한 번에 500자까지 보낼 수 있어요.
- 1:1 쪽지(dm)는 보낸 사람과 받은 사람만 읽을 수 있어요. 운영진도 볼 수 없어요.

----------------------------- 여기부터 복사 -----------------------------
{
  "rules": {
    ".read": false,
    ".write": false,
    "members": {
      ".read": "auth != null && root.child('members').child(auth.uid).exists()",
      ".write": false
    },
    "chat": {
      ".read": "auth != null && root.child('members').child(auth.uid).exists()",
      ".indexOn": ["t"],
      "$id": {
        ".write": "auth != null && root.child('members').child(auth.uid).exists() && ((!data.exists() && newData.child('u').val() === auth.uid) || (data.exists() && !newData.exists() && (data.child('u').val() === auth.uid || root.child('members').child(auth.uid).child('op').val() === true)))",
        ".validate": "newData.hasChildren(['u', 'n', 'x', 't']) && newData.child('n').val() === root.child('members').child(auth.uid).child('n').val() && newData.child('x').isString() && newData.child('x').val().length > 0 && newData.child('x').val().length <= 500 && newData.child('t').isNumber() && newData.child('t').val() <= now"
      }
    },
    "dm": {
      "$key": {
        ".read": "auth != null && root.child('members').child(auth.uid).exists() && ($key.beginsWith(auth.uid + '__') || $key.endsWith('__' + auth.uid))",
        ".indexOn": ["t"],
        "$id": {
          ".write": "auth != null && root.child('members').child(auth.uid).exists() && ($key.beginsWith(auth.uid + '__') || $key.endsWith('__' + auth.uid)) && ((!data.exists() && newData.child('u').val() === auth.uid) || (data.exists() && !newData.exists() && data.child('u').val() === auth.uid))",
          ".validate": "newData.hasChildren(['u', 'x', 't']) && newData.child('x').isString() && newData.child('x').val().length > 0 && newData.child('x').val().length <= 1000 && newData.child('t').isNumber() && newData.child('t').val() <= now"
        }
      }
    },
    "inbox": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        "$from": {
          ".write": "auth != null && root.child('members').child(auth.uid).exists() && (auth.uid === $from || auth.uid === $uid)"
        }
      }
    },
    "seen": {
      "$uid": {
        ".read": "auth != null && auth.uid === $uid",
        ".write": "auth != null && auth.uid === $uid"
      }
    },
    "online": {
      ".read": "auth != null && root.child('members').child(auth.uid).exists()",
      "$uid": {
        ".write": "auth != null && auth.uid === $uid && root.child('members').child(auth.uid).exists()"
      }
    }
  }
}
